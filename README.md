# Shopwise – Customer Intelligence Dashboard

A data-driven customer analytics dashboard designed to analyze customer purchasing behavior, identify shopping patterns, and provide actionable business insights using Python, Flask, Pandas and Machine Learning.

## Features

- Customer behavior analysis
- Purchase prediction
- Customer insights and analytics
- CSV dataset upload
- Data visualization
- Purchase pattern analysis
- Customer segmentation and analysis

## Technologies Used

- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- HTML
- CSS
- JavaScript

## Dataset

The project supports CSV files containing customer demographics, browsing activity, product information, purchase history and purchase indicators.

A sample dataset is included in the repository.

## Installation & Setup

1. Clone the repository:

   `git clone https://github.com/YOUR_USERNAME/Shopwise-Customer-Analytics.git`

2. Navigate to the project directory.

3. Install dependencies:

   `pip install -r requirements.txt`

4. Run the Flask application:

   `python app.py`

5. Open the dashboard using the frontend URL configured for your project.

## Project Purpose

This project demonstrates the application of data science, machine learning and customer analytics to retail customer behavior and purchase prediction.
